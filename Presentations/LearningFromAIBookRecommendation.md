# Learning with AI
## Topic 1: AI Book Recommendations
### Preston Jackson

---

## What is it?
- AI Book Recommendations
- Utilizes Reactive Machine AI (Simplest AI Model)
- Generates a mix of Books based on user data

---

## How does it Work?
- Take books from API database
- Take books fro user stored books (Bookeep)
- Compare books from API to books in user logs, applying each book with a point value
- Return list of top scoring books to display on BookHelp

---

## What Did I Learn?

1. This AI does not always generate the same number of outputs like I expected
2. AI does do really well at making recommendations
3. Model has some biases based on the point system and favors more recent books
4. AI will translate books for itself and will recommend non-English books unless manual filtering applied
